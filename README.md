# Smart Farmer Assistant App

A modern, responsive web application built for farmers to access useful agricultural support features such as market prices, crop recommendations, and disease detection guidance.

## Features

- Market price insights for different crops and regions
- Crop recommendation guidance
- Disease detection support and educational content
- Multilingual interface support
- Clean, mobile-friendly UI for easy access on the go

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui-inspired components

## Getting Started

1. Clone the repository
2. Install dependencies

```bash
npm install --legacy-peer-deps
```

3. Start the development server

```bash
npm run dev
```

4. Open http://localhost:3000 in your browser

## Build for Production

```bash
npm run build
```

## Notes

If you run into a peer dependency resolution issue while installing packages, the project currently works well with:

```bash
npm install --legacy-peer-deps
```
